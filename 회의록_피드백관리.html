📋 JSONBin.io 설정 방법 (완전 무료 · 3분)
1. jsonbin.io → Sign Up (이메일 가입)
2. 로그인 후 상단 API Keys → Secret Key 복사
3. 아래 Secret Key 입력 후 🆕 새 Bin 자동 생성 클릭
4. Bin ID가 자동 입력됨 → 💾 저장
